# Country Finder

Search for a country to see its flag, capital, region, and population.

Built with HTML, CSS, and vanilla JavaScript. Country details come from the
[REST Countries dataset](https://github.com/mledoze/countries), population
figures from the [World Bank API](https://api.worldbank.org/), and flags from
[FlagCDN](https://flagcdn.com/).

## Run it

Open `index.html` in your browser. An internet connection is required to load
the country data, population figures, and flags.

## What I practiced

- Fetching data with `fetch` and `async`/`await`
- DOM manipulation and rendering results
- Filtering and mapping arrays
- Handling loading, empty-result, and error states
